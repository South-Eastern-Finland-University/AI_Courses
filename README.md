# Applied AI & Modern Full-Stack Engineering

**Total Credits:** 10 ECTS (260 hours)
**Duration:** 14 Weeks
**Focus:** From AI foundations to production-ready, full-stack AI applications.

---

## Main Focus: Practical Application

**"Learn-by-Doing" Methodology**

- **Focus on Practical Tools:** This course prioritizes hands-on experience with industry-standard tools over abstract theory.
- **No Pure Theory:** All "lectures" are hands-on jupyter notebook (or similar practical platform) sessions. Concepts are introduced only to be immediately implemented.
- **Step-by-Step Progression:** We start with simple building blocks and progressively layer complexity to reach advanced implementations.
- **Example-Driven Learning:** Mini-projects serve as concrete guides, allowing students to generate ideas, design and implement before their final project.

- **Tutorials:** Let's use as many tutorials as possible to guide the students through the course. Let's use ready-made youtube material, we don't need to create our own tutorials.

- **Model Solutions:** Make model solutions for teacher from all hands on lectures and labs using free tier services if available.

- **Example Projects:** Make a repo of example projects to introduce some project ideas.

---

## Course Overview

This expansive course takes students from the fundamentals of AI tools and web architecture to building production-ready, AI-powered applications. It combines deep theoretical understanding of LLM mechanics with practical,cc hands-on development using modern tools like Supabase, Firebase, n8n, and Flutter.

## Technology Stack

- **AI Models & Tools:** Gemini, Google AI Studio, Gemini CLI.
- **Frontend:** HTML5, CSS3, Tailwind CSS.
- **Backend & Automation:** n8n, LangChain.
- **Data & Auth:** Supabase (SQL, Vector Store, Realtime), Firebase (Auth, Firestore).
- **Deployment:** GitHub, Vercel.
- **Prototyping:** Lovable, Bolt.
- **Mobile & Payments:** Flutter, Stripe.
